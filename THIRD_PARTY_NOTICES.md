# Standards and comparative sources

MoonSCIM is an original implementation. It does not include or translate code
from another SCIM SDK.

Normative behavioral sources:

- IETF RFC 7643, *System for Cross-domain Identity Management: Core Schema*.
- IETF RFC 7644, *System for Cross-domain Identity Management: Protocol*.
- IETF RFC 9865, *Cursor-Based Pagination of SCIM Resources*.

Later extension specifications are tracked for forward compatibility but are
not claims of v0.1 support:

- IETF RFC 9944, SCIM device schema extensions.
- IETF RFC 9967, SCIM profile for Security Event Tokens.

The RFCs are used as specifications. Their text and examples are subject to
the IETF Trust Legal Provisions. Repository fixtures are independently written
and use fictional identities.
